# 铁路危险货物运输路径审批与风险复核平台

源提示词编号：8。包含危险货物运输单编组、候选路径生成、MapLibre 路网风险叠加、Turf 里程测算、安全/运营/应急逐区段会签、替代方案与审计基线。

## 技术栈

Angular、Angular Material、NgRx、Angular Router、HttpClient、RxJS、MapLibre GL、Turf.js、TypeScript。

## 运行

```bash
npm install
npm run dev
```

开发地址：http://localhost:62051

```bash
npm run build
```

## 封锁处置令（应急调度）

线路临时封锁后，值班员在「封锁处置令」页登记封锁区段（如 天水—宝鸡西），系统自动比对各运输单路径中的共用区段、列出受影响运输单，并先冻结它们的原路径与许可证号。

- **逐单独立核对**：替代路径（不经封锁区段且发到站连通）、接卸站资质（按品类代码）、许可有效期、安全/运营/应急三方会签；四项全过才可放行，任一不过留在待处理，不拖累已完成单。
- **退回重算**：替代路径改动或会签所依赖的路径变化，原会签失效、已放行单退回待处理；许可失效（或重开页面时发现过期）同样退回重算。
- **协同保存**：两名调度员同时保存同一处置令时，后到者保存会检测到服务器更新并自动合并——本终端确有改动的单保留本终端结论，其余单以对方最新进度为准；勾选「模拟写入失败」可验证写入失败后各单结论不丢失、并按令号自动重试。
- **断点接续**：处置令（封锁范围、逐单状态、待会签、放行结果、版本号）持久化在浏览器 localStorage，关闭页面重开后自动加载并按当前日期重算许可有效期。

## 原有功能

- 路径编组（workspace）：危险货物运输单编组、候选路径生成。
- 风险地图（risk-map）：MapLibre 路网风险叠加、Turf 里程测算。
- 多角色审批（approval）：安全/运营/应急逐区段会签与审计基线。
